# ScummViewer

ScummViewer is a **free software** tool for exploring and visualizing **SCUMM**
game data. It focuses on decoding, inspecting, and faithfully rendering assets
from classic LucasArts adventure games, starting with **SCUMM v5**
(Monkey Island 2, Indy, Monkey VGA).

This is **ScummViewer v2** — a clean, SwiftUI-idiomatic rewrite focused on
clarity, correctness, and documentation.

ScummViewer is part of the [ScummKit](https://www.scummkit.org) project.

---

## Goals

- 📦 Browse SCUMM game files and resources  
- 🖼️ Decode and render original assets accurately  
- 🧠 Understand and explain SCUMM data formats and behavior  
- ✍️ Produce high-quality technical documentation alongside code  
- 🧪 Serve as a learning and reverse-engineering project  

**Non-goals (for now):**
- Full multi-version SCUMM support
